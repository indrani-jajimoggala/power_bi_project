# Sales Performance Analysis Dashboard

## 📊 Project Overview

This project is a **Sales Performance Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes online sales data to understand revenue performance, units sold, transaction volume, product category performance, regional sales distribution, and payment-method trends.

The goal of this project is to transform raw sales data into meaningful visual insights that can support business decision-making.

---

## 🎯 Business Objectives

The dashboard was created to answer key business questions such as:

* How does revenue change over time?
* Which product categories generate the most revenue?
* Which regions contribute the most to sales?
* How many units are sold across different categories and regions?
* Which payment methods are used most frequently?
* Which product categories contribute most to overall revenue?
* How many transactions have been recorded?
* How is actual revenue performing against the target?

## 📈 Dashboard Visualizations

The dashboard includes the following visualizations:

### 1. Revenue Trend

A line chart showing **Total Revenue by Month** to identify changes and trends in sales performance over time.

### 2. Units Sold by Category and Region

A clustered column chart comparing **Units Sold** across different product categories and regions.

### 3. Total Revenue KPI

A card displaying the overall **Total Revenue**.

### 4. Units Sold KPI

A card displaying the total number of **Units Sold**.

### 5. Revenue by Region

A donut chart showing the contribution of different **regions to total revenue**.

### 6. Regional Sales Map

A filled map visualizing sales distribution across different **regions**.

### 7. Units Sold by Payment Method

A column chart comparing units sold across different **payment methods**.

### 8. Regional & Category Revenue Table

A table providing detailed revenue information by **Region and Product Category**.

### 9. Revenue Target Gauge

A gauge visual used to monitor **revenue performance against the target**.

### 10. Transaction Count

A KPI card displaying the total number of **transactions**.

### 11. Revenue by Product Category

A funnel chart comparing **Total Revenue across product categories**.

## 🔍 Key Analysis Areas
